# mc-ai-builder 宽松版提示词 · 让 AI 自己设计遗迹

> 配套：[施工版提示词](STRUCTURE-BUILDER-PROMPTS.md)（精确到方块，适合已定稿复刻）、[美术需求案](STRUCTURE-ART-BRIEF.md)（尺寸与识别点来源）。
>
> **这一版是给"我要它自己设计"用的**。施工版把坐标、格数、窗间距全写死了，AI 只会照砌答案，
> 出来就是一个平台 + 一圈墙 + 一座塔的"亭子"，没有任何遗迹该有的残缺感。宽松版反过来：**只锁 4 件事，其余全放开**。

---

## 0. 先诊断：上一版为什么像亭子

| 现象 | 原因 | 这一版怎么改 |
|---|---|---|
| 只有平台 + 直墙 + 一座塔 | 我把每个部件都写成了坐标，AI 没有设计空间 | 只说"一座比墙高的瞭望塔"，位置由它决定 |
| 墙全是完整的、顶是平的 | 施工版没有任何"破损"指令 | 强制要求**至少一面墙塌出缺口**、塔顶缺一角 |
| 看起来是新的 | 没有风化层：没有苔藓、没有铜绿、没有锈 | 把"废弃了三十年"写进定位句，并要求铜绿从下往上爬 |
| 四角蜂蜜黄大块很突兀 | `honeycomb_block` 2 格叠在塔顶，体积太大 | 信标只留 1 格，且要求它自己决定放几颗、放在哪 |
| 黑色竖条像悬浮黑板 | `tinted_glass` 竖直整格放，就是一块黑板 | 改成"破窗/空洞"：直接留空或放 `glass_pane` 的一半 |
| 对称得像图纸 | 我给的坐标就是对称的 | 明确写"不要对称，四角不要一样高" |

**核心：遗迹感 = 破损 + 不对称 + 风化 + 被用过又放弃的痕迹。** 这四样缺一样，出来的就是新建筑。

## 1. 宽松版模板（套任意建筑）

复制这段，把 `<...>` 换掉就行。**顺序别改**，定位句在最前，AI 会先建立"这是什么地方"的概念，再设计细节。

```text
设计一座 <这是什么 / 谁建的 / 为什么被废弃>。
占地不超过 <W×D> 格、高度不超过 <H> 格，建在 y=1 以上。
主体用 <材质族 A>，工艺件用 <材质族 B，可含少量更贵重的方块>，标志物用 <1-3 个点缀方块>。
必须出现：(1) <识别物 1>；(2) <识别物 2>；(3) <识别物 3>。
它已经被废弃很久：至少一处墙体塌出参差缺口，至少一个顶部结构缺角，箱子/设备有的空了有的翻倒，
墙脚有苔藓和爬藤，金属件从下往上氧化，地面有碎块和散落的材料。
四边不要对称，四角不要一样高，窗户数量和位置你决定。
布局、塔位、开口、破损位置全部由你设计，要像一个真被用过又放弃的地方，不要像新盖的亭子。
禁止：完整无缺的城墙、圆顶、旗杆、雕像、玻璃幕墙、现代简约风格。
```

## 2. 八座推荐提示词（每条整段可直接粘）

### 2.1 云港遗迹

```text
设计一座被遗弃很久的云上港口哨站。它曾经有驻守的人，现在只剩断墙、空箱子和没人收的灯。
占地不超过 20×20 格、高度不超过 15 格，建在 y=1 起的平台上，而且平台本身就是残缺的，不要做成完整方形。
主体用磨制安山岩、平滑石这类灰石；工艺件用切制铜，一部分已经氧化发绿；标志物用 1 到 3 颗琥珀色的硫晶，原版里用 honeycomb_block 表现。
必须出现：一座明显比围墙高的瞭望塔；四角里至少两个角还立着矮塔、另外两个只剩基座；一条从门口通往塔脚、中间已经断掉的铜镶线。
它已经被废弃很久：围墙至少塌出一个参差缺口，塔顶缺一角，地面散着碎石和翻倒的空箱子，
墙脚长苔藓和爬藤，铜绿从下往上蔓延，窗洞全是破的、没有玻璃。
四边不要对称，四角不要一样高。布局、塔位、开口和破损位置全部由你设计，要像一个真有人的哨站被放弃后的样子。
禁止：完整无缺的城墙、圆顶、旗杆、雕像、玻璃幕墙、现代简约风格。
```

### 2.2 酸泵站

```text
设计一座建在酸滩边上、被丢下的抽酸泵站。它是工业设施，不是神庙，人不在了但机器还立在那儿。
占地不超过 13×13 格、高度不超过 9 格。
主体用平滑石和磨制安山岩，机械件用磨制深板岩和铁栏杆，标志物用 1 颗琥珀色硫晶和一个黄铜色配件（honeycomb_block）。
必须出现：两台立式压力罐，一高一低、罐身能看到液位窗；一座矮小的控制塔；一段被酸蚀穿、断在半路的铜管。
它废弃已久：护堤有一角塌了，罐体表面有锈斑，地面被酸水侵蚀出坑，几只箱子翻倒、其中一只里面空了，
管口下面积着酸绿色的残液（用 lime_stained_glass 局部表现），墙脚有苔藓。
不要把它做成漂亮的工业风展览品——要像个停产后被遗忘了三十年的地方。
四边不要对称，罐子不要摆得一样高。布局和破损位置你自己决定。
禁止：完整的围合城墙、烟囱、蒸汽朋克管道缠绕、城堡垛口。
```

### 2.3 高压观测塔

```text
设计一座孤零零立在霜原上的高压观测塔，观测员早就撤走了，设备还挂在墙上。
占地不超过 11×11 格、高度不超过 32 格。
主体用凿制石砖加平滑石基座，加固件用切制铜箍，标志物用 1 颗琥珀色硫晶（honeycomb_block）。
必须出现：一根笔直、很高、不收分的塔身，从下到上一圈一圈的铜箍；顶部一个比塔身宽出去的平台；塔底堆着被丢下的箱子。
它废弃已久：铜箍有几圈已经锈断脱落，顶部平台缺一角、边缘参差，塔身有几处破窗和裂口，
塔里没有楼梯也没有地板，能直接看到顶；塔基周围散着木板、碎石和断掉的缆索。
不要把塔设计成尖顶或收分——它是一根直的观测杆。平台上的仪器可以由你决定，但必须残破。
四边不要对称。布局和破损位置你自己决定。
禁止：圆顶、尖塔、外挂楼梯、天线阵列、玻璃花房。
```

### 2.4 真菌苗圃

```text
设计一座真菌森林里被荒废的苗圃，以前的看守在这里种菌，现在只剩床架和失控长出来的蘑菇。
占地不超过 11×11 格、高度不超过 6 格，整体必须非常扁、非常低。
主体用平滑石矮台，苗床用苔藓块，工艺件用少量切制铜镶边，标志物用 1 颗琥珀色硫晶。
必须出现：几块抬高的方形苗床（数量你决定，但看得出是排布过的，不是散的）；两种颜色的巨型蘑菇，长在床里也长到床外；
一块倒掉的苗床板和散落的木头。
它荒废已久：部分镶边已经断裂，苗床塌了一两块，蘑菇从裂缝里长出来、盖住了半边台面，
中央的小棚只剩框架，地面有落下的蘑菇伞和积水。
不要做成整齐的农田——要像一个没人管之后自己长回去的地方。
数量和位置你自己决定，不要做成一圈对称的九个格子。
禁止：完整围合的围墙、屋顶、高塔、真实农田垄沟。
```

### 2.5 坠毁飞艇

```text
设计一艘坠毁在云层里的运货飞艇残骸，它撞进了云岩坡里，一半埋着、一半露着。
占地不超过 20×7×6 格（长×高×宽），船体沿一个方向斜躺着。
船体用已经氧化的风化切制铜，骨架肋骨用深色钢块表现，标志物用少量琥珀色配件。
必须出现：一段胶囊形的船体，两端收窄；每隔几格就露出一根肋骨的结构感；一处被撕开的破口，能看进空船内部。
它坠落已久：尾部整段断掉、掉了队、往下陷进云里；断口参差、铜板向外翻卷，而不是整齐切口；
船顶还挂着几根断掉的缆索和破烂帆布；船里有翻倒的空箱子和洒出来的货。
不要再给它加完整的气囊——气囊已经炸没了，最多留一束撕裂的吊索残骸。
破裂、倾斜角度、断口形状你自己决定。禁止：完整飞艇、气球球体、齐柏林飞艇、桅杆、舵轮。
```

### 2.6 熔管城市

```text
设计一座废弃的硫晶祭城，它是三层同心圆台逐层收进去、逐层抬高，现在被遗弃了。
占地不超过 40×40 格、高度不超过 15 格，三层圆台半径大致是 20、14、8，你自己决定精确尺寸。
主体用磨制安山岩和磨制深板岩，标志物用琥珀色的硫晶块，酸池用酸绿色玻璃表示。
必须出现：三层明显的同心圆台、每层边缘有一圈矮墙和缺口；四根独立于圆台之外的高柱；中层一圈硫晶柱和中央的祭台。
它废弃已久：某几层矮墙塌了大段，圆台边缘缺齿，四根柱子有一根断了半截，硫晶碎了几颗掉在地上，
台阶上堆着碎石，酸池溢出漫到台面上，苔藓从边缘往里长。
不要做成干净对称的竞技场——要看出这里曾经有仪式、后来没人了。
半径、台阶位置、缺口和破损位置你自己决定。
禁止：罗马斗兽场式环形看台、圆顶、王座雕像、橙红色熔岩（那不是酸）。
```

### 2.7 启明星祭坛

```text
设计一座立在整个云海最高处、荒废了的高空祭坛。它曾经是终点，现在只剩台阶和碎裂的晶柱。
占地不超过 9×9 格、高度不超过 6 格，周围空旷，没有任何其它建筑。
主体用平滑石，台阶面用切制铜，标志物用琥珀色硫晶块。
必须出现：三级往内收的台阶；四角立着的晶柱；正中央一组竖立的、像核心一样的三格结构。
它荒废已久：有晶柱断了一截，台阶崩了边角，中央的核心缺了一块，铜面上有氧化斑，
缝隙里长出苔藓，地上散着掉落的晶体碎片。四个角不要一样高。
不要把它做成完整对称的仪式台——要像一个被用过很多年、然后被放弃的地方。
破损位置和台阶细节你自己决定。
禁止：雕像、拱门、围栏、第二栋建筑、把周围地面铺装出去。
```

### 2.8 梦眠祭坛

```text
设计一座月球森林里的小型梦眠神龛，是玩家或旧时信徒自己搭的木龛，很旧、很小、还在用。
尺寸上限 7×7 格、高度不超过 3 格，不要建大。
用淡色的原木做四角柱，淡色木板做台面，顶上用会发光的青绿色叶块当灯罩（原版用 verdant_froglight）。
中央放一块深色石板当祭坛台，上面有青色符文光（原版用 sea_lantern），这是全场唯一光源。
它已经很旧：木柱有点歪，台面缺一块木板，叶冠疏了几处、漏光，四周围着散落的碎木和月之花。
四面完全敞开，没有墙没有门；不要石砖、不要金饰、不要第二层。
歪斜程度和残缺位置你自己决定，但总高不能超 3 格。
禁止：大型神殿、石砌、围合结构、第二处光源、蓬松树冠。
```

## 3. 让它更"遗迹"的加分句（接在任意一条后面）

```text
再破一点：让三分之一的墙是缺口，缺口不要平齐，要参差；塔顶和圆台边缘都要缺齿。
```

```text
加时间痕迹：金属件从下往上氧化变色，石头缝隙里长苔藓和藤蔓，地面上铺一层碎石、断木和掉落材料。
```

```text
加"人"的痕迹：留下临时修补的木板、堆起来的箱子、用剩下的材料搭的矮墙、被踩出的一条土路。
```

```text
压掉现代感：去掉所有规整的直线和等距重复，每个立面都要有一处不对称。
```

## 4. 三轮迭代法（比一次写完更好）

1. **第一轮：只要形体。** 用 §2 的提示词，砍掉"它废弃已久"那一段，只留定位句 + 体量 + 必须出现。
   先把"是什么"定对，别让破损干扰它理解结构。
2. **第二轮：加破损。** 发 `现在让它看起来废弃了很久：` + §3 前三句，让它自己在形体上做减法。
3. **第三轮：加细节。** 发 `再加细节：苔藓、断木、碎石、翻倒的箱子、爬藤，以及临时修补的痕迹。不要改动主体结构。`

> 每轮结束都**导出一次 `.schem`**。三轮比一次到底稳，而且每一步你都能挑最接近的那张。

## 5. 验收：遗迹五问

出图后不用看需求案，就问自己这五个问题，任何一个"否"就继续迭代：

1. **它有缺口吗？** 至少一面墙或一处顶是塌的，边缘参差。
2. **它对称吗？** 如果四角一样高、四面一个样，返工。
3. **它有风化吗？** 苔藓 / 铜绿 / 锈 / 碎石，至少有其中两种。
4. **它像"被用过"吗？** 有箱子、有材料堆、有临时修补的痕迹，不是空壳展品。
5. **远看认得出是哪座吗？** 对照[美术需求案 §1.2 剪影指纹](STRUCTURE-ART-BRIEF.md)：云港=王冠、酸泵站=双肺、观测塔=针与盘、苗圃=棋盘、飞艇=逗号、熔管城市=婚礼蛋糕、启明星=小金字塔、梦眠=一盏灯。

## 6. 两份提示词怎么选

| 你的目的 | 用哪份 | 特征 |
|---|---|---|
| 要它自己设计、要遗迹感、接受每次结果不一样 | **本文档** | 只锁体量 + 材质族 + 3 个识别物 |
| 已经定稿、要精确复刻进世界生成代码 | [施工版](STRUCTURE-BUILDER-PROMPTS.md) | 坐标、格数、窗间距全写死 |
