## 1. 通用规则（四个 Boss 都适用）

### 1.1 剪影第一

Boss 在 30 格开外就要认得出是谁。判定标准：把模型压成纯黑剪影，仍能区分四者。

- 涅斐勒 = **横向流线**（鲸形，长尾）
- 赫菲斯托斯 = **纵向厚重**（宽肩、短腿、拳头过大）
- 阿佛洛狄忒 = **上窄下宽**（裙摆/触须式下半身），P3 再放大
- 阿瑞斯 = **人形机械**（铁傀儡骨架，肩甲外扩）

### 1.2 弱点必须"看得见、打得着"

代码里的弱点坐标就是美术的硬约束（实体局部空间，y 自脚底向上，**−z 为正面**）。弱点在模型上必须有一块**明确的高对比区域**，且与判定体积大致对应。

| Boss | 弱点 id | 相对坐标 | 半径 | 暴露时机 | 视觉要求 |
|---|---|---|---|---|---|
| 涅斐勒 | `tail_vent` | (0, 0.8, +4.2) | 1.2 | 常驻 | 尾端一圈散热鳍 + 内部橙光，尾部必须够长（≥4 格）才放得下 |
| 涅斐勒 | `air_sac_left/right` | (±1.6, 2.2, −0.4) | 1.2 | P3 | 背部两块半透明气囊，平时收缩，P3 膨胀并发白 |
| 赫菲斯托斯 | `vent_left/right` | (±2.75, 8.25, 0) | 1.6 | 常驻 | 双肩各一个圆形散热口（格栅），持续冒蒸汽 |
| 赫菲斯托斯 | `core` | (0, 8.0, +1.7) | 1.6 | P3 | 背部炉心（`furnace` 骨），平时被 `furnace_cover` 盖住，P3 打开露出熔岩腔 |
| 阿佛洛狄忒 | `sulfur_core` | (0, 2.2, −0.9) | 1.5 | 常驻 | 胸口硫晶核，最大的高对比点（整只 Boss 的视觉中心） |
| 阿佛洛狄忒 | `acid_sac_left/right` | (±1.2, 1.6, +1.0) | 1.2 | P3 | 背面两个半透明酸囊，P3 由暗转亮（黄绿） |

> 铁律：**常驻弱点 = 发光裂隙/机械开口**；**阶段弱点 = 平时闭合，开阶段时"打开"**（要有动作，不能只是换贴图）。

### 1.3 护甲板要能被"打掉"

抽象 Boss 的护甲板是独立血量（涅斐勒 4 板、赫菲斯托斯 6 板、阿佛洛狄忒 4 板）。美术上需要：

- 主板数量与模型上的**大装甲块一一对应**（6 板就是 6 块可辨识的大甲片）；
- 至少两档破损表现（完好 / 裂开泛红），用**贴图变体 + 掉落碎块粒子**实现，不要做 6 套模型；
- 板全碎时露出本体材质（更暗、更裸露，与装甲区分明显）。

### 1.4 前摇必须可读

战斗数值里每个招式都有前摇（0.9–3 s）。美术要在**模型 + 粒子**两层同时给信号：

| 前摇时长 | 模型动作 | 辅助 |
|---|---|---|
| 0.5–1.0 s | 明显预备（后拉 / 抬臂 / 张口） | 局部高光或颜色变亮 |
| 1.0–2.0 s | 全身姿态变化（下蹲 / 蓄力 / 悬浮升高） | 地面预警圈、粒子柱 |
| ≥2.0 s | 持续导光（弱点/核心发光），可叠加抖动 | 音效 + 大范围粒子 |

### 1.5 边界（不在本需求内）

- 月球 Boss（另案）；
- 水星 **太阳鱼**（`SunfishEntity`）：悬空巡游的精英群居生物，判定箱 1.6×0.6，按"生物"而非 Boss 做，部件预算与动画复杂度都低一档；
- 火星 **恶魔蛾**（`DemonMothEntity`）等召唤物：作为 Boss 的"配件"统一风格即可。

### 1.6 制作规范

- 模型一律在 **Blockbench** 里做；`.bbmodel` 只是制作期工作文件：放 `build/scratch/models/<name>.bbmodel`（`build/` 已忽略），任务结束删除，**不入库**。
- 实体格式**允许**旋转体与逐面 UV（GeckoLib / Bedrock），不必受装备那套 box UV 限制；但坐标仍应对齐整数格，避免贴图像素拉伸。
- 每只 Boss 一份贴图集（不拆多张），阶段差异用**同尺寸贴图变体**（如 `xxx.png` / `xxx_phase2.png`），文件名与实体 id 对齐。
- 动画命名固定：`idle` / `walk`（或 `fly`）/ `attack` / 每招一个专属名 / `phase_transition` / `death`。

## 2. 涅斐勒 · 云鲸（金星 · 巡航空战）

### 2.1 定位
金星大气层的巨型漂浮生物，体型接近小型鲸。战场是开阔空中/云台，玩家用弓箭与投射武器打。整体气质：**安静、巨大、带电**。

### 2.2 体型与剪影
- 判定箱 7.0 × 4.0，实际模型可做到 **宽 9~10、长 12~14**（横向流线，不占高度）。
- 必须有：头（钝圆，无眼或眼很小）、背脊、两侧胸鳍、**长尾（≥4 格，尾端是弱点）**、腹部褶皱。
- 剪影禁忌：不要做"会飞的鱼"，要有鲸的厚重感；尾巴不能短。

### 2.3 结构部件清单（建议 ≥45 部件）
主体（头/下颌/躯干 3 段/尾 3 段）、胸鳍 ×2、背鳍 ×3、腹褶 ×4、气囊 ×2、尾端散热口（弱点）、体表凸起/寄生物 ×6、口腔内部、眼/须。

### 2.4 材质与色板
| 用途 | 颜色 |
|---|---|
| 主皮 | `#E8D9A0` 淡金（受光）/ `#BFAE78` 暗部 |
| 腹部 | `#F2F0E6` 云白 |
| 阴影/深部 | `#2F4F6B` 深蓝灰 |
| 雷云强调 | `#6E5AA8` 紫 + `#BFE3FF` 电弧蓝白 |
| 弱点 | `#FF8A3C` 橙（常驻）/ `#C8D93B` 黄绿（P3 气囊） |

材质：**皮革感**（柔软、有褶），不要金属；背部可加薄薄一层半透明"云膜"。

### 2.5 阶段
| 阶段 | 血量 | 外观变化 |
|---|---|---|
| P1 巡航 | 100–60% | 正常淡金皮，缓慢漂浮 |
| P2 雷云 | 60–25% | 体表出现紫蓝电弧纹（贴图叠加 + 粒子），背鳍张开，漂浮高度提高 |
| P3 力竭 | 25–0% | 气囊膨胀发白、尾焰变暗红、身体下沉贴地，动作变迟缓 |

### 2.6 动画
`idle`（缓慢浮动 + 尾摆）、`fly`（巡游）、`tail_sweep`（尾扫，正后方 6 格）、`dive`（俯冲，直线 20 格）、`cloud_burst`（云爆弹，张口）、`summon`（召唤云帆鳐）、`phase_transition`（雷云化，1.5 s）、`death`。

### 2.7 粒子与音效提示
- 前摇：尾部/口部聚集白色云团粒子；俯冲前身体后仰并升 2 格。
- 音效基准：`PHANTOM_AMBIENT` / `PHANTOM_SWOOP` / `RAVAGER_ATTACK`，低沉而非尖锐。

### 2.8 贴图规格
256×256 单张（现 256×128 偏紧）；P2/P3 各一张同尺寸变体。

## 3. 赫菲斯托斯 · 巨像（金星 · 地表阵地战）

### 3.1 定位
金星地表的熔炉守卫巨像，玩家在熔岩平台间拉扯。气质：**笨重、滚烫、机械锻造**。

### 3.2 体型与剪影
- 判定箱 6.0 × 9.0，模型可到 **高 10~11、宽 8~9**（含肩甲外扩）。
- 必须有：巨大双拳（单拳 ≈ 2 格）、宽肩（散热口在肩顶）、短粗腿、背部炉心（P3 露出）、腰部液压/管线、头部小且深陷在肩甲之间。
- 剪影禁忌：不要做成"放大的人"，肩宽必须显著大于腰宽（≥2:1）。

### 3.3 结构部件清单（建议 ≥50 部件）
躯干（胸/腹/腰 3 段）、肩甲 ×2（含散热口格栅）、上臂 ×2、拳 ×4（指节）、腿 ×2、脚 ×2、背部炉心 + 3 片护盖、颈部管线 ×6、铆钉/铆钉排 ×8、锁链/吊挂 ×2。

### 3.4 材质与色板
| 用途 | 颜色 |
|---|---|
| 主装甲 | `#5A2A1E` 暗锈红，高光 `#7A3B28` |
| 金属结构 | `#6B6462` 灰钢 / `#3A3634` 暗钢 |
| 熔岩/热源 | `#E8A33B` 琥珀 → `#FF6A1E` 熔橙（自发光） |
| 灰烬/积碳 | `#2A2624` |
| 弱点散热口 | 内部 `#FFB347` 发光 + 外部格栅 `#8A6A2A` |

材质：**厚重金属**，边缘必须有磨损与积碳；不要干净的新钢。

### 3.5 阶段
| 阶段 | 血量 | 外观变化 |
|---|---|---|
| P1 熔岩拳 | 100–66% | 正常，拳部有熔岩裂纹 |
| P2 蒸汽 | 66–33% | 肩部散热口全开并持续喷汽，装甲缝隙透白汽，体表挂水珠状高光 |
| P3 炉心过载 | 33–0% | 背部炉盖打开、炉心裸露（最强发光点），全身裂纹发红，头部抬起 |

### 3.6 动画
`idle`（呼吸 + 蒸汽脉动）、`walk`（沉重，落地有 2 帧定格）、`lava_punch`（前摇 0.9 s，后拉—砸下）、`slag_throw`（1.2 s 抬手—投掷）、`steam_vent`（2 s 全身抖动 + 张口）、`quake_stomp`（1.4 s 抬腿—踏地）、`overload_burst`（3 s 蓄力，仅 P3）、`plate_break`（单板破碎、后仰）、`death`。

### 3.7 粒子与音效
- 前摇：脚部/拳部熔岩粒子上升；过载时全身粒子外扩。
- 音效基准：`RAVAGER_ROAR`（吼）、`LAVA_POP`（循环底噪）、`GENERIC_EXPLODE`（爆发）、`FIRE_EXTINGUISH`（蒸汽）。

### 3.8 贴图规格
256×256 单张 + P2/P3 变体（P3 需要独立的"炉心发光"蒙版）。

## 4. 阿佛洛狄忒 · 硫之女王（金星 · 熔管层终局）

### 4.1 定位
金星熔管层的最终 Boss，三形态递进。气质：**腐化之美**——华丽但恶心，紫 + 酸绿。

### 4.2 体型与剪影
- 判定箱 4.0 × 6.0；P3「女王」形态**体型 ×2**（代码直接放大），因此模型必须在大尺寸下仍不糊。
- 必须有：上半身人形（头/胸/双臂）、**胸口硫晶核**（最大视觉中心）、下半身**裙摆/触须**（非双腿，流体感）、背部双酸囊（P3）。
- 剪影禁忌：不要做成"穿裙子的女人"；下半身要像融化的蜡/酸液柱。

### 4.3 结构部件清单（建议 ≥48 部件）
头（面甲/王冠/发丝状触须）、胸甲 2 段、硫晶核（核心 + 外环）、肩 ×2、臂 ×2、手 ×2、裙摆 3 层（每层 6–8 片）、背部酸囊 ×2、腰部挂饰、漂浮碎晶 ×4。

### 4.4 材质与色板
| 用途 | 颜色 |
|---|---|
| 主甲 | `#4A2A4E` 暗紫，高光 `#6E3F73` |
| 硫晶核 | `#C8D93B` 酸黄绿（自发光）+ `#F2F0A0` 亮芯 |
| 酸液/裙摆 | `#7FA83C` 半透明 → `#4E6B2A` 暗部 |
| 骨骼/装饰 | `#D8CBA8` 旧骨白 |
| 腐蚀痕 | `#2A1F2B` |

材质：**半透明 + 金属描边**的组合；裙摆要能透出内部结构。

### 4.5 阶段
| 阶段 | 血量 | 外观变化 |
|---|---|---|
| P1 酸潮 | 100–66% | 正常，裙摆流动，胸口晶核稳定发光 |
| P2 茧 | 66–33% | **结茧**：外层包一层半透明酸壳（覆盖 80% 身体），壳体有裂纹显示剩余护壁 |
| P3 女王 | 33–0% | 破茧而出，体型 ×2，酸囊外露并发亮，王冠完整，周身硫火环 |

### 4.6 动画
`idle`（裙摆起伏 + 晶核脉动）、`acid_wave`（酸浪，前方扇形）、`acid_needle`（酸针连射）、`cocoon_in`（结茧，1.5 s 收缩）、`cocoon_hit`（茧受击裂纹）、`cocoon_break`（破茧，2 s 爆发）、`sulfur_ring`（硫火环，P3）、`shockwave`（高压冲击波）、`death`。

### 4.7 粒子与音效
- 酸：`SNEEZE` / `SLIME_BLOCK_PLACE` / `SQUID_INK`（酸液喷溅）；晶核常驻 `FLAME` 小粒子。
- 破茧：`GLASS_BREAK` + `EXPLOSION`；阶段切换 `WITHER_SPAWN` 作为"女王降临"的音效骨架。

### 4.8 贴图规格
256×256 单张 + P2（茧）/ P3（女王）变体；晶核单独一块 32×32 的自发光 UV 区，便于做脉动。

## 5. 阿瑞斯 · 熔核巨像（火星 · 温度驱动）

### 5.1 定位
已完成的 GeckoLib 角色（44 骨、10 段动画、4 张阶段贴图）。本轮**不重做模型**，只做质感统一与阶段区分。

### 5.2 现有资产
`geo/entity/ares.geo.json`（128×128，44 骨）、`animations/entity/ares.animation.json`（idle / walk / attack / eruption / storm / overload / self_destruct / slam / summon / core_purge）、贴图 `ares.png` / `ares_phase1/2/3.png` / `ares_shield.png` / `ares_wing.png`。

### 5.3 需要改的
| 项 | 现状 | 要求 |
|---|---|---|
| 阶段贴图区分 | 4 张尺寸相同但明度差异小 | P1 铁灰冷调、P2 熔橙裂纹、P3 全红 + 核心白热；同屏对比要一眼分得出 |
| 护盾 | `ares_shield.png` 499 B | 半透明六边形能量壳，边缘亮、内部网格；受击时对应位置闪光 |
| 翼 | `ares_wing.png` 738 B | 与主体同色系（金属骨架 + 熔岩膜），P2 展开时不能像贴纸 |
| 核心 | `core` / `core_ring` 骨已有 | 温度越高越亮：<500℃ 暗红、500–1500℃ 橙、>1500℃ 白热 |
| 剪影 | 人形机械 | 肩甲外扩、头部后缩，与铁傀儡原型拉开距离 |

### 5.4 阶段与温度映射（美术侧）
- < 500℃ 脆化：模型整体降饱和、金属发青灰，核心暴露；
- 500–1500℃ 正常：锈红 + 局部熔光；
- > 1500℃ 狂暴：全身熔线，护盾展开（半透明），动作幅度加大。

### 5.5 验收
四张阶段贴图并排截图，非专业玩家能在 3 秒内指出"哪张最热"。

## 6. 交付物与验收

### 6.1 每只 Boss 的交付清单
- [ ] 编辑源只留制作期暂存（`build/scratch/`），确认仓库里没有 `.bbmodel` / 预览图
- [ ] 实体贴图（256×256）+ 阶段变体
- [ ] 动画清单齐全（命名见 §1.6），循环动作首尾同姿态
- [ ] 弱点区域在模型上有明确高对比标记，且坐标与 §1.2 表一致
- [ ] 三视图截图（正 / 侧 / 背）+ 阶段对比图
- [ ] 游戏内截图（由用户在游戏内确认，agent 不能代替）

### 6.2 验收标准（逐条打勾）
- [ ] 压成纯黑剪影，四个 Boss 互不混淆
