## 1. 定位与气质

金星熔管层的最终 Boss，战场是结满硫磺结晶的地下管道与酸液池。玩家在狭窄管道里被她用酸浪、酸针、硫火环与冲击波逼着走位，中期她结茧、后期女王降临并限时 4 分钟。

气质三件套：

1. **腐化之美** —— 构图与姿态永远是「优雅的」，材质永远是「烂掉的」：雕花金属 + 腐蚀孔洞、骨白装饰 + 酸蚀麻点、半透明液体 + 悬浮碎晶；
2. **甜美的恐怖** —— 面甲下半张脸是完好的女性轮廓（唇、下颌），上半张脸被面甲吞掉，只透出两点紫光；
3. **宫殿级压迫感** —— 她比玩家高 3 倍以上，裙摆铺满脚下，**仰视才有女王感，但三视图必须正交**（见 §4.3 的取舍）。

### 1.1 与另外三个 Boss 的分工（压成纯黑剪影仍可辨）

| Boss | 剪影特征 | 一句话 |

| 阿瑞斯 | 人形机械、肩甲外扩 | 机械的 |

## 2. 定位与尺度（单位：方块；局部坐标 **−Z = 正面**，原点 = 实体脚底 y=0）

### 2.0 ⚠ 比例锁定（2026-11 修订；上一版就死在这里）

**上一版做出来像个男的，根因是三个数字**，不是画风、也不是模型不够细：

| 项 | 上一版（错） | 这一版（对） | 读感差别 |
|---|---|---|---|
| 肩 : 腰 | 22 : 14 = **1.57 : 1** | 14 : 7 = **2.0 : 1** | 腰只收 36% → 方肩战士；收 50% → 有腰 |
| 髋 : 肩（裙顶 vs 肩宽） | 14 : 22 = 0.64（胯比肩窄） | 15 : 14 = **1.07**（胯比肩宽） | 胯比肩窄 = 男；胯比肩宽 = 女 |
| 头高 / 总高 | 15/94 = **16%**（4.4 头身） | 10/88 = **11%**（8.8 头身） | 大头方脸 = 男；小头长颈 = 女王 |
| 胸部 | 被 `plate_1_front` 一整块平板甲抹平 | 两个软块**从肋廓前凸 4 单位** | 平甲 = 男；凸起 = 女 |

**三条硬指标（出图后必须量，不达标就重出）**：

1. **肩宽 / 腰宽 ≥ 2.0**
2. **髋宽 / 肩宽 ≥ 1.05**（裙顶宽于两肩）
3. **头高 / 总高 = 0.10–0.12**（头要小）

再叠一条：**腰线是一道清晰的水平硬边**，上下材质在这里断开 —— 没有这条线，锥形会被读成"袍子"。

## 3. 剪影规范

### 3.1 必须成立的五条轮廓

1. **沙漏 + 锥形**：肩 0.88 → **腰 0.44（唯一收束点）** → 髋 0.94 → 裙底 3.3；腰以上是「收」，腰以下是「**只增不减**」；
2. **腰是断点**：腰线处有一道**水平方向的硬边**（腰甲下沿），这是「上半身 / 下半身材质切换」的分界，也是晶核所在的横线；
3. **王冠 5 尖**：尖必须**分离**（尖与尖之间留缝），像硫磺结晶簇，不要做成圆箍；
4. **裙摆硬边**：三层甲叶的**外轮廓是折线**（每片 3–4 个直角/钝角），底部不齐、长短交错，禁止圆润的花瓣边；
5. **背后两个鼓包**：背面视图腰线两侧各一个半透明球鼓，是背面唯一的高光面。

### 3.2 剪影禁忌

- ❌ **两条人腿**（现有模型就是腿，必须换掉）—— 腰线以下不许出现任何柱状分叉；
- ❌ **普通长裙 / 礼服**（收腰 + 拖尾 + 布料褶皱）—— 是**熔蜡柱**，不是布料，褶皱必须是「流下来的层」而不是「折起来的褶」；
- ❌ 裙摆做成圆台/圆锥的干净曲面 —— 必须能数出 8 片/层的硬边；
- ❌ 肩甲外扩到超过 1.9 —— 那是 Ares / 赫菲斯托斯的剪影语言；
- ❌ 手臂过长或持杖 —— 她的手是**施法器官**（细长、骨节分明），保持垂放或半抬，三视图里不拿武器；
- ❌ 胸口再多一颗晶核 / 额头再来一颗 —— **全身只有一颗硫晶核**，位置由代码锁死。

### 4.2 每个视图必须看到什么（少了就是不合格）

**① 正面（−Z 对准镜头）**
- 王冠 5 尖，正中一尖最高；**面甲遮住上半脸**，只留下颌与唇线，面甲内透两点紫光（`#9B4FBF`，弱发光）；
- **腰线正中的硫晶核**：六棱核体 + 雕花外环 + 四道辐条；这是她全身**唯一的白热亮点**（芯 `#F2F0A0` → 环外 `#C8D93B`）；外环直径 1.1–1.25，**把判定球 r=1.5 的范围圈住一半以上**（关键，见 §8.2）；
- 胸甲**上下两段**（上胸段 / 下胸段），两段之间一道 0.1 的缝，缝里透暗紫光 —— 这就是 **4 块甲片里的 2 块**；
- 左肩甲 / 右肩甲各一块，向斜上翘出 3 根骨白棱刺（`#D8CBA8`）—— **另外 2 块甲片**；
- 双臂垂放或半抬，前臂有骨白环扣 ×2/臂；手指 **4 指细长如骨**（不要画成人类 5 指，也不要多指）；
- 裙摆：三层 × 8 片，正视能数出**最下层 8 片的左右边界**；底部 2–3 滴悬垂酸滴；
- 背部酸囊：被身体挡住 → **正视图靠「王冠 + 晶核 + 锥形裙」三件辨识**。

**② 侧面（脸朝画面左，最能读结构，也是最严格的一张）**
- 裙底离地 **0.15**（这条缝必须看得出来，她是悬滑的）；
- 侧轮廓线：裙底最外点 → 向上收 → 腰线硬边（最窄 0.45 半宽）→ 胸甲前凸 0.15 → 下颌 → 面甲前缘 → 王冠尖；
- **硫晶核的前凸量 0.9**（z=−0.9），必须比胸甲更靠前，侧视图里能看到它**凸出在腰部前方**并投出一小片绿光在裙摆上；
- 面甲与头之间留一道缝，透出光；发丝状酸液触须从后脑垂到腰际（正/侧/背三视图都要有，长度不一，最长到 y≈2.0）；
- 裙摆侧看是**层层叠压**（上层压住下层的上缘 0.1），不是一片平整曲面；
- 酸囊在**下背**（y=1.6，z=+1.0）：侧面看是腰后一个鼓包，被一片**贝壳状暗紫护盖**半遮住（P1 遮 70%）。

**③ 背面（+Z 背对镜头）**
- **4 块甲片的接缝必须数得清**：左肩甲 / 右肩甲 / 上背甲 / 腰背甲（背面的甲片划分与正面不同，见 §5.1 注）；
- **两个酸囊正对镜头**：直径 1.15 的半透明鼓包，囊内可见浑浊黄绿液体与一颗更亮的核（`acid_sac_core_l/r`），外圈一圈 8 片小鳞；
- 酸囊护盖：两片贝壳状暗紫盖板，P1 遮 70%，**背面是它的展示面**；
- 裙摆背面：同样三层 8 片，最下层中央一片**缺口**（露出内部酸液柱的暗部 `#2C3A18`）；
- 王冠背面：能看到 5 尖的根部与后脑的两根短触须；
- 轮廓光最强的一张：暗紫在灰底上，全靠背后一圈冷白轮廓光分离。

- **P1 → P2**：裙摆**向内收拢**、身体缩成一个茧，裙底的酸滴被吸回去 —— 「她把自己藏起来了」；

### 8.1 对齐表（局部坐标，−Z = 正面，y 自脚底）

**注意 ± 符号**：代码里 `acid_sac_left` 是 **x = −1.2**。模型自身右侧是 +X，别做反（建完用 `which_side` / `check_sides` 验一遍）。

### 8.2 ⚠ 唯一的美术—代码分歧点（二选一，别两头将就）

代码把常驻弱点放在 **y = 2.2**，而判定箱高 6.0 —— 那是**身高的 37%**，落在**腰线**上，不是胸腔。

- **方案 A（本文采用，推荐）**：新模型总高 5.5，`core` 就嵌在**腰线正中的腰甲上**，视觉往前凸 0.5 格（判定球中心仍在 −0.9，r=1.5 完全覆盖）。好处：不用改代码；「腰上的核」在腐化女王身上反而更像**子宫/心脏外露**，比胸口宝石更恶心更贴设定。
- **方案 B（想要真·胸口核）**：`AphroditeEntity` 第 102 行的 `2.2D` 改成 `3.4D`（一个数字），模型按胸口核做。代价：代码改动 + 存档里的弱点位置概念变化 + 旧文档 `BOSS-ART-BRIEF.md` §4.1「胸口硫晶核」要跟着改。

> **不要**出现「美术画在胸口、代码判定在腰部」的第三种状态 —— 玩家会照着图画的位置打空。

### 8.3 视觉铁律

1. 常驻弱点 = **发光开口**：核体必须是「裂开的甲片里露出的一颗会发光的晶体」，不是一块贴在甲上的颜色；
2. 阶段弱点 = **平时关闭、开阶段时打开**：酸囊必须有**护盖翻开 + 膨胀**两段动作，不能只换贴图；
3. 判定球 r=1.5 比核体视觉（0.55）**大 5 倍**，所以外环、辐条、光晕三件套的作用就是**把可打范围画出来** —— 外环直径 1.1–1.25 是硬指标，不是装饰。

## 9. 动画清单（时长对齐代码前摇）

### 11.4 使用要点（决定成败的六条）

1. **画幅 16:9**（2000×1125 / 1536×864）。三视图用 1:1 会让三个视图挤在一起，用 3:4 会逼模型竖排。
2. **两遍投喂法（强烈推荐）**：先只出**正面**（把主提示词里「三个视角横向等距并排」改成「单个正面全身，正对镜头」）→ 选最满意的一张 → 把它当 **character reference / image prompt** 再投「同一个角色的侧面视图（脸朝画面左）」「同一个角色的背面视图」，最后把三张拼版。**一次性出三视图的失败率远高于分三次出再拼**。
3. **侧面是最容易崩的一张**：必须显式写「裙底与地面之间留一道细缝」「晶核向前凸出」，否则模型会把她画成站立的裙装女人。
4. **晶核是验收第一关**：位置必须在**腰线正中（不是胸口）、向前凸、比全身任何东西都亮**。如果出在胸口 —— 那是 §8.2 方案 B 的位置，按本文方案 A 必须重出。
5. **禁「裙子」**：提示词里只要出现 gown / dress / 花瓣裙 / 拖地长裙，模型就会给她加腿。用 `acid column / melted wax / layered plates`。
6. 出图后按 §4.2 的逐视图清单打勾，缺「王冠 5 尖 / 腰线晶核 / 三层裙摆 / 背面双酸囊」任一即重出，**不要靠后期补**。
