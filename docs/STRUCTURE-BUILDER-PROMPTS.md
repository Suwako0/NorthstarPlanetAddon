> 配套：[美术需求案](STRUCTURE-ART-BRIEF.md)（定剪影与材质）、[图像提示词包](STRUCTURE-AI-PROMPTS.md)（出概念图）。
> 本文件是**第三种提示词**：喂给 [mc-ai-builder](https://github.com/Justcnds/mc-ai-builder) 直接生成方块建筑。
> **如果你嫌这套写得太死、出来像个亭子**：用 [宽松版提示词](STRUCTURE-BUILDER-FREEFORM.md)——只锁体量和识别物，破损与布局交给 AI 自己设计。
>
> **工具事实**（据其 README 与 `construction-skill`）：
> 本地网页工具（`http://localhost:3001`），AI 输出的是调用 `VoxelBuilder` 的 **JavaScript 代码**，不是 JSON 蓝图；
> 支持中英文、参考图模式，导出 `.schem` / `.litematic` / Axiom / 数据包 / 单指令；方块名跨 1.8–1.21+ 自动转换。
> 关键 API：`builder.fill / walls / line / set / setDoor / drawRoofBounds / drawPolyRoof / drawCylinder /
> drawPolygon / drawPyramid / drawSpiralStairs / drawHanging / scatter`，方块写法 `'oak_stairs?facing=north,half=top'`。
> 我核对了 README、`construction-skill` 与自定义脚本 API 文档；**没有在真实环境跑过这个工具**，
> 所以 §4 的落地流程按它的导出格式写，第一次用请先按 §5 试一轮。

## 0. 三条铁律（决定成功率的全部）

### 铁律 1：模组方块先用原版替身，落地再 `//replace`

mc-ai-builder 的方块名转换表**只认原版方块**。`northstar_planet_addon:sulfur_crystal_block` 这类名字它不认识，
写进提示词只会得到两种结果：报错，或者被它“猜”成别的方块。

所以流程固定为：**用原版替身搭 → 导出 `.schem` → 落地后 WorldEdit `//replace` 换成模组方块**（替身表见 §1）。
替身只要“颜色与体积对了”就行，纹理差异一次 `//replace` 全解决。

### 铁律 2：一次一座，分 2–3 步

LLM 一次能稳定写出的建筑代码量有限，41×41 的三层圆台写一遍必然出现“层高错位 / 半截没盖完”。
下文每座都给了**主提示词**（一步版）和**分步版**（每步一个独立代码块），出错就改用分步版。

### 铁律 3：每个代码块末尾都已内联这三句

下文所有可以复制的文本块，末尾都自带这三句约束，**整段粘即可，不用再手动补**：

```text
只使用我在上面列出的方块，不要自己添加其它方块；不要加任何我没要求的屋顶、尖塔、旗杆、雕像、藤蔓；
地面 y=0 以下不要放置任何方块；整座建筑完整生成在 x=-32..32、z=-32..32、y=0..40 范围内。
```

## 1. 方块替身表（模组方块 → 原版 → 落地替换）

采样值来自 `assets/northstar_planet_addon/textures/block/*.png` 实测；替身取 1.21.1 可用且色值最接近的原版方块。

| 模组方块 | 外观 | 原版替身 | 落地命令 |
|---|---|---|---|
| `cloud_stone` 云岩 | 蓝灰石质 `#586070→#8898a0` | `tuff`（或 `andesite`） | `//replace tuff northstar_planet_addon:cloud_stone` |
| `tungsten_block` 钨块 | 暗钢灰绿 `#303830/#485850` | `polished_blackstone`（或 `deepslate_tiles`） | `//replace polished_blackstone northstar_planet_addon:tungsten_block` |
| `sulfur_crystal_block` 硫晶块 | 琥珀金 `#a88018→#f8e8a8` | 柱身 `honeycomb_block`；发光位 `glowstone` | `//replace honeycomb_block northstar_planet_addon:sulfur_crystal_block` |
| `pressure_tank` 压力罐 | 深灰钢 `#282828/#484848` | `polished_deepslate` + `iron_bars` 液位窗 | `//replace polished_deepslate northstar_planet_addon:pressure_tank` |
| 硫酸液面 | 酸绿 `#88e048` | `lime_stained_glass`（先铺一层当液面标记） | 落地后换成实际硫酸流体池 |
| `stripped_moonlight_log` 去皮月华原木 | 淡紫 `#a8a0b8/#c0c0d0` | `stripped_birch_log` | `//replace stripped_birch_log northstar_moon_addon:stripped_moonlight_wood` |
| `moonlight_planks` 月华木板 | 淡紫板面 `#a8a0b8` | `birch_planks` | `//replace birch_planks northstar_moon_addon:moonlight_planks` |
| `moonlight_leaves` 月华树叶 | 青绿发光 `#409078/#68b8a8` | `verdant_froglight`（发光）或 `azalea_leaves`（只求形） | `//replace verdant_froglight northstar_moon_addon:moonlight_leaves` |
| `dreamsleep_altar` 梦眠祭坛 | 深靛 + 青符文 `#282040`/`#88e0f8` | `deepslate_tiles` + `sea_lantern` 符文 | 落地直接换成祭坛方块 |
| `ares_altar` 阿瑞斯祭坛 | 黑曜 + 余烬 `#181010`/`#783818` | `obsidian` + `magma_block` 内凹 | 单方块，不需要 builder |

> **不要**用 `green_stained_glass` 顶替硫晶——硫晶是琥珀金，不是酸绿。游戏里一个是信标、一个是伤害源。

## 3. 修改指令模板（生成完接着发）

mc-ai-builder 会把当前画布的代码带进上下文，这些短句可以直接接着发，不必重写整段。

换材质：

```text
把建筑上所有 honeycomb_block 换成 glowstone，其余结构完全不变。
```

开窗：

```text
把四面围墙上每 5 格开一个 1×2 的窗洞，填 tinted_glass，不要动其它结构。
```

加楼梯：

```text
在中央塔北面内侧加一段贴墙的 stone_brick_stairs 楼梯，从 y=1 通到 y=12，不要改动墙体。
```

加灯：

```text
在四角围墙内侧各挂 1 条 chain，下面接 1 只 lantern，不要改墙体。
```

压高度：

```text
把整座建筑整体降低 2 格，让最低点贴到 y=0。
```

改尺寸：

```text
把这层圆形平台的半径从 20 改成 15，其余结构按比例保持。
```

去多余物：

```text
删除所有我没要求的屋顶、旗杆、雕像、藤蔓和装饰方块。
```

只重画局部：

```text
只重新生成中央塔（5×5、高 12），平台和围墙保持原样。
```

> 每改一次就**导出一次**：上下文越长，越容易把已经对的部分改坏。`.schem` 就是你的存档点。

## 4. 落地流程（导出 → 进游戏 → 换成模组方块）

1. **导出** `.schem`（WorldEdit 格式）——后续调整都在游戏里做，不回到网页。
2. 进游戏对准地面：`//schem load <名字>` → `//paste -a`（`-a` 忽略空气，避免覆盖周围地形）。
3. **对齐坐标**：原点在平台中心，粘贴后先看一眼包围盒，确认底面落在 y=0 而不是悬空。
4. **批量替换替身**（一条一条来，替换前先 `//undo` 备份）：
   ```text
   //replace tuff northstar_planet_addon:cloud_stone
   //replace polished_blackstone northstar_planet_addon:tungsten_block
   //replace honeycomb_block northstar_planet_addon:sulfur_crystal_block
   //replace polished_deepslate northstar_planet_addon:pressure_tank
   //replace stripped_birch_log northstar_moon_addon:stripped_moonlight_wood
   //replace birch_planks northstar_moon_addon:moonlight_planks
   //replace verdant_froglight northstar_moon_addon:moonlight_leaves
   ```
5. **补功能方块**：箱子换成带战利品表的箱子（模组里对应 `chests/cloud_harbor` 等 11 张表）；`lime_stained_glass` 池换成实际硫酸流体池。
6. **光照检查**：AI 生成的结构常常内部全黑；代码里的 `RuinPalette.detail()` 会补灯笼与玻璃带，手搭时别漏。

## 5. 常见失败与修法

| 症状 | 原因 | 修法 |
|---|---|---|
| 报“未知方块” | 提示词里写了模组方块 ID | 换 §1 替身，落地再 `//replace` |
| 塔被收成尖顶 / 多出屋顶 | LLM 的“建筑直觉” | 已内联“不收分、平顶、不要屋顶”；仍出现就发 §3 的「去多余物」 |
| 层高错位、二层悬空 | 一次生成层数太多 | 改用分步版，一层一条指令，且每条都写“整体抬高到 y=…” |
| 生成到一半截断 | 代码量超预算 | 降尺寸（41→31）、拆成 2–3 步；每步导出后再继续 |
| 窗洞数量不对 | 没给数量 | 写死“每 5 格一个、1×3”，不要写“开一些窗” |
| 门朝向反了 | 没指定方向 | 一律写“北面（-Z）开门” |
| 尺寸对但“不像” | 少了识别点 | 回 §2 每座“验收”三条，把缺的那条加成一句新指令 |
| 整体偏半格 / 悬空 | 原点理解不同 | 粘贴后 `//move 0 -1 0` 微调，不要回网页改 |
