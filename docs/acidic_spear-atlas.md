# acidic_spear · 酸蚀矛（3D 武器模型 + 128×128 图集）

参考图：`docs/previews/acidic_spear-reference.png`

- 几何长度：**59.8 单位 ≈ 3.74 格**（旧版 48 单位 ≈ 3.0 格，本轮加长约 25%）

## 攻击方式：套用三叉戟

| 项 | 实现 |
|---|---|
| 握持 | getUseAnimation → UseAnim.SPEAR，和原版三叉戟同一套抬手姿势 |
| 蓄力 | 按住右键，getUseDuration = 72000；松开时蓄力 < 10 tick 不投掷 |
| 投掷 | 生成 ThrownAcidSpear，初速 2.4，重力 0.05（比雪球沉，看得出是重矛） |
| 离手 | 投出后手上不再有矛（stack.shrink(1)），创造模式不消耗 |
| 命中 | 9 点投掷伤害 + 腐蚀叠层（最多 5 层）+ 40% 中毒，与近战同一套规则 |
| 落地 | 落地掉出本体（投掷一次磨损 1 点），捡回可继续用；耐久只剩 1 时拒绝投掷 |
| 音效 | TRIDENT_THROW |
| 旧技能 | 「酸液迸发」移到**潜行 + 右键**，数值与冷却不变 |

> 不做忠诚 / 激流 / 引雷——那是原版三叉戟的专属附魔，本模组走腐蚀路线。

## 握持位置（本次修正）
