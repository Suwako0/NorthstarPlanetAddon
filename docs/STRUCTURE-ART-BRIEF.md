## 1. 通用规则（所有结构共用）

### 1.1 硬约束：概念图必须"能照着搭"

这些建筑不是 NBT 模板，是特征代码按坐标摆方块。因此：

- 概念图里**每一块都必须是 1 格方块**，不允许圆角、斜切面、曲面幕墙、悬挂软质布幔——搭不出来；
- **体量不许超出 §0 表的代码尺寸**（美术放大 1.5 倍 = 世界生成要重写整段坐标，不是改贴图）；
- 允许的自由度只有三种：**方块类型的替换、方块的堆叠细节、非方块的装饰件（铁栏杆/锁链/灯笼/玻璃/格栅）**。

### 1.2 剪影指纹（30 格外必须分辨）

把图压成纯黑剪影，仍然要能对上号。这是验收第一关：

| 结构 | 剪影指纹 | 一句话 |
|---|---|---|
| S1 云港遗迹 | **方形盘 + 四角短柱 + 中央高塔** | 王冠 |
| S2 酸泵站 | **低台 + 两个立式圆罐** | 双肺 |
| S3 观测塔 | **极细高杆 + 顶部方盘** | 针与盘 |
| S4 真菌苗圃 | **扁平方台 + 八个等距鼓包** | 棋盘的洞 |
| S5 坠毁飞艇 | **横躺胶囊 + 垂下断尾** | 逗号 |
| S6 熔管城市 | **三层同心递收圆台** | 婚礼蛋糕 |
| S7 启明星祭坛 | **小台阶 + 四根等长柱 + 中央尖** | 小金字塔 |
| S8 梦眠祭坛 | **矮木框 + 平展叶冠** | 一盏灯 |

**冲突检查**：S1 与 S3 都"方盘+柱"，靠 **S3 塔身细长比 ≥ 6:1、S1 塔身粗短（5 格底面 / 12 格高）** 区分，两者不可画成同一比例。

### 1.3 着色域：三个色族不许混

所有结构只能在这三个族里取色，跨族混用是"廉价感"的主要来源：

| 色族 | 归属 | 采样值（实测） |
|---|---|---|
| **A 云岩冷灰** | 平台 / 地基 / 墙体主色 | `#586070` `#788090` `#8898a0`（云岩）；磨制安山岩 ≈`#8a8a8a`；磨制深板岩 ≈`#4a4a4f`；平滑石 ≈`#a0a0a0` |
| **B 硫晶琥珀** | 信标 / 柱头 / 祭坛核心（**唯一光源色**） | `#685010` `#a88018` `#f0e078` `#f8e8a8`（硫晶块）；`#d8a838` 黄铜 |
| **C 铜与酸绿** | 金属工艺 / 机械件 / 腐蚀 | 切制铜 ≈`#c16d4f`；风化切制铜 ≈`#6a9a88`；铜格栅 ≈`#7fa08c`；硫酸 ≈`#88e048` `#b0e048`；苔藓 ≈`#6a7a2f` |

> **铁律**：硫晶是**琥珀金**（`#a88018 → #f8e8a8`），硫酸是**酸绿**（`#88e048`）。两者在游戏里是两个东西，
> 概念图里把硫晶画成荧光绿是最常见的错——它会让人以为是酸（伤害源），而不是信标（地标）。

### 1.4 材质语言（跨结构共用）

| 角色 | 方块 | 视觉规则 |
|---|---|---|
| 结构壳体 | 磨制安山岩 / 磨制深板岩 / 凿制石砖 | 大面平整，**接缝 1 格可数**；不做砖纹乱铺 |
| 地面 | 平滑石 | 比壳体亮一档，用来把建筑从地面"托"起来 |
| 工艺件 | 切制铜 / 风化切制铜 / 铜格栅 | **只走横线**（箍、梁、地面镶线）；铜绿只出现在**下风侧/底部**，表现向腐蚀过渡 |
| 开口 | 染色玻璃（半透黑）/ 铁栏杆 | 玻璃**不做窗框套窗框**；铁栏杆只做直棂，不做花纹 |
| 光 | 灯笼（暖黄）挂锁链、海晶灯（冷青白）做机器 | 暖光=人造/有人住，冷光=机械/无人。**同屏最多两种光** |
| 信标 | 硫晶块 | 单颗 ≤ 2 格高；不许铺成"发光地毯" |
| 本模组件 | 云岩（平台）、钨块、压力罐、酸泵 | 云岩 `#586070→#8898a0`；钨块 `#303830/#485850/#889890`；压力罐 `#282828/#484848/#889090` |

### 1.5 环境与光照

| 星球 | 环境 | 用途 |
|---|---|---|
| 金星云海 | `ambient_light=0.35`（偏暗）、`effects=overworld`（淡蓝天空）、y 190–300、下方是无底云海 | 建筑像**浮在云上的孤岛**；概念图默认光照 = **黄昏侧逆光**，光从左上来，云海从画面底部把建筑托起来 |
| 金星酸潮滩 | 硫酸液面 + 硫磺结壳 + 苔藓 | S2 的背景，地面要有**酸性黄绿水洼**但不得淹没建筑 |
| 金星真菌森林 | 巨型蘑菇 + 苔藓 + 孢子雾 | S4 的背景，暖绿低调，**孢子不能糊住建筑轮廓** |
| 火星 | 暗红铁石 `#783820/#482010` + 干冰 + 沙尘 | S9 的背景，暖橙雾，**祭坛必须比背景亮一档** |
| 月球月林 | 靛蓝夜空 + 月华木 `#a8a0b8` + 青蓝树叶 `#409078/#68b8a8`（发光 12）+ 温泉蒸汽 | S8 的背景，冷靛蓝高调，唯一暖色是月之花 `#d89828` |

### 1.6 禁止项（画面里出现即返工）

- 任何玩家、生物、怪物、NPC、马匹、飞艇船员——建筑图里不要人；
- 任何文字、招牌、旗帜上的字、UI、水印、logo、罗盘、坐标；
- 写实砖石 / 哥特教堂 / 奇幻城堡 / 玻璃幕墙科幻塔 / 霓虹灯 / 全息投影；
- 有机曲面墙、软质布幔、藤蔓盖住整面墙（腐蚀只允许在底部和接缝）；
- 画到画面外的建筑（必须整栋入画，留 ≥ 8% 画边距）；
- 凭空加第二栋同款建筑（"复制粘贴"是 AI 出结构图最常见的败笔）。

### 1.7 交付前三道检查

1. **剪影关**：压黑能不能对上 §1.2？
2. **方块关**：有没有任何一个形状不是 1 格立方体？
3. **色族关**：数一数画面里出现几个色族，超三个就是跑偏了。

## 2. 逐座需求

### S1 云港遗迹 · `cloud_harbor`

**定位**：金星云海上"曾经有人的地方"，也是 `弹道校准器` 的保底获取点。玩家从围墙缺口进入，中央塔下有两只箱子，75% 概率有 1 只黄铜执事在看守。

**代码体量（精确）**：21×21 平台（四角切去 1 格），平台厚 3；环形围墙高 6，**每 5 格开一个窗**（窗在第 3–5 层）；四角各一座 2×2、9 格高的晶塔，塔顶 1 格硫晶；中央塔 5×5 外壳（半径 2）、12 格高、南面 3 宽 2 高的门洞；塔顶铺云岩，中枢 1 颗硫晶。

**材质表**：平台 平滑石；围墙 磨制安山岩；晶塔 磨制安山岩 + 硫晶块顶；塔顶 云岩；窗 染色玻璃；通风 铜格栅；四角 锁链 + 灯笼；地面中线 1 格宽的切制铜镶线。

**识别点（必须画出来）**：
1. **四角晶塔等距**（21 格平台上四角，间距一眼可数）；
2. **中央塔明显高于围墙**（12 vs 6，塔高约围墙两倍）；
3. **地面铜线从门口直通塔下**（一条 1 格宽的暖铜色线，是唯一的"人工动线"）。

**构图**：16:9 横向，四分之三俯视（仰角 30–35°），塔尖入画不切顶，云海从画面下缘漫过平台底。

**专属禁止**：画成城堡 / 加旗杆 / 加圆形穹顶 / 塔身开满窗 / 晶塔比中央塔高。

**验收**：
- [ ] 平台四角能被切角看见（不是完整正方形）
- [ ] 围墙窗洞可数 ≥ 4 个且等距
- [ ] 四座晶塔高度一致、顶色为琥珀金
- [ ] 中央塔有明确门洞，塔顶单一信标
- [ ] 有铜镶线 / 铜格栅 / 锁链灯笼中至少两种工艺件

### S2 酸泵站 · `acid_pump_station`

**定位**：酸潮滩上被遗弃的抽酸设施，"能修好"的感觉要读得出来。3 只箱子散在泵体两侧。

**代码体量（精确）**：13×13 平台（切角）、厚 3；环形围墙半径 6、高 4（每 5 格开窗）；中央 5×5 小塔、5 格高、硫晶顶；**泵体 = 3 个压力罐方块：x=+3 处叠 2 格高、x=−3 处 1 格高**（代码就是不等高的两组，美术可按"两台泵、一高一低"理解）。

**材质表**：平台 平滑石；围墙 磨制安山岩；泵体 压力罐 `#282828/#484848/#889090`（带 1 格竖液位窗）；塔顶 硫晶；地面 硫酸/苔藓斑（环境，非本体）。

**识别点**：
1. **两台立式泵罐一高一低**（2 格 / 1 格）分居院子两侧、都有液位窗，是全图最"机械"的东西；
2. 围墙**比人矮**（4 格，像护堤不像城墙）；
3. 中央小塔是"控制室"，明显矮于 S1/S3（5 格）。

**构图**：4:3，四分之三俯视，酸水洼从画面外侧逼近平台底部，泵体不入阴影。

**专属禁止**：把泵体画成大烟囱 / 加管道盘绕成"工业朋克" / 围墙加垛口 / 硫晶和硫酸同色。

**验收**：
- [ ] 两台泵罐能一眼数出是"2 台"，一高一低，且都有竖窗
- [ ] 围墙高度看起来 < 平台宽度的 1/2
- [ ] 画面里有酸绿，但建筑本体没有任何酸绿发光

### S3 高压观测塔 · `observation_tower`

**定位**：金属霜高地上孤零零的观测塔，赫菲斯托斯的剧情召唤点在塔底（玩家用 `压力阀` 开战）。

**代码体量（精确）**：11×11 底座（半径 5）、厚 3，塔身四周各留 2 格环形台；塔身 7×7 外壳（半径 3）、**30 格高**；顶层平台 9×9（向外悬挑 1 格）；顶部 1 颗硫晶；铜箍 `RuinPalette.truss()` **每 4 格一圈**贴在四个方向。

**材质表**：底座 平滑石；塔身 凿制石砖；铜箍 切制铜；顶台 平滑石；信标 硫晶；底部 4 只箱子（3 普通 + 1 校准器）。

**识别点**：
1. **细长比 ≈ 1:4.3（7 宽 / 30 高）**，全模组最高竖构，一眼就它；
2. **每 4 格一道铜箍**，从上到下可数（约 7 道）；
3. **顶部 9×9 平盘比塔身宽**，边缘外挑——三面看到明显"T"字形。

**构图**：**3:4 竖构图**（16:9 装不下 32 格，塔会变成一根细线）；仰角 20–25°（不要俯视，否则塔身被压短），顶端与云海逆光。

**专属禁止**：塔身收分成圆锥 / 加直升机场标记 / 顶部画成玻璃花房 / 加外挂楼梯（代码里没有）。

**验收**：
- [ ] 塔高 ≥ 画面高度的 70%
- [ ] 铜箍等距且可数 ≥ 5 道
- [ ] 顶部平台明显比塔身宽，且只有 1 颗琥珀信标
- [ ] 塔底有 4 只箱子（并排成 2×2 更好）

### S4 真菌苗圃 · `fungal_nursery`

**定位**：真菌森林里的温室/苗圃，产出农业材料。氛围在八座里最"温"。

**代码体量（精确）**：11×11 平台（切角）、厚 2；**8 个 2×2 苔藓床**呈 3×3 网格去中心分布；每床一株巨型蘑菇（**红/棕交替**：偶数是棕、奇数是红），茎 1 格、冠 1 格，总高 3；中央 1 格硫晶（"小棚"占位）。

**材质表**：平台 平滑石；菌床 苔藓块 ≈`#6a7a2f`；蘑菇 红 `#b02a20` / 棕 `#8a6a4a`；中央 硫晶；角落 锁链灯笼；环境 巨型蘑菇林 + 孢子雾。

**识别点**：
1. **八块等距的方形苔藓床**（3×3 缺中心），俯视图就是棋盘；
2. **红棕交替**的蘑菇冠，颜色成对出现；
3. 全场**最低最扁**（总高 5），和人视线齐平。

**构图**：4:3 或 1:1（偏俯视 45°，让八床排布可数），背景蘑菇林虚化但不得盖住台面。

**专属禁止**：画成真实农田 / 加大量作物盖住床 / 蘑菇画成写实菌盖 / 用荧光绿做蘑菇（那是酸色）。

**验收**：
- [ ] 苔藓床可数出 8 块，排布是 3×3 缺心
- [ ] 蘑菇颜色明显两族交替（红/棕）
- [ ] 建筑高度看起来是最矮的一座
- [ ] 有暖黄灯笼，没有冷光

### S5 坠毁飞艇 · `crashed_airship`

**定位**：云海/雷暴带里的失事飞艇，气囊核心的获取点。故事感最强的一座。

**代码体量（精确）**：船体长 **15 格**（x −7…+7）、宽 5（z −2…+2）、高 4（y 0…3），两端收窄成 1 宽 → 胶囊形；**每 3 格一根钨块肋骨**（横跨船腹）；右侧 **断裂尾段 x +8…+11 逐格下沉**（`drop=(dx-7)/2`，四格后掉 2 格），尾段内部清空；破口在船体右侧中部 2×2；3 只箱子（含气囊核心）。

**材质表**：船体 **风化切制铜** ≈`#6a9a88`（铜绿）；肋骨 **钨块** `#303830/#485850`；破口 空气（透视进去可见暗内腔）；环境 云海 + 雷暴云 + 孢子。

**识别点**：
1. **横躺的胶囊**（长宽比 3:1）与断裂的下沉尾段形成逗号剪影；
2. **外露的钨钢肋骨**：每隔 3 格一根深色横梁，从破口可以数；
3. 铜绿外壳 + **一处 2×2 的黑色破口**，是唯一暗斑。

**构图**：16:9 或 4:3 横向，从"船头斜 45°+略俯视"看，让断裂尾段在画面远端往云里沉；必须能在画面里放下一段云海，船体 30% 没入云。

**专属禁止**：画成完整飞艇（必须坏）/ 加气囊球体（代码里没有；**要画气囊也只能画成一束破烂吊索+残片**）/ 加螺旋桨以外的幻想装饰 / 尾巴断口画成整齐切口（要撕开感）。

**验收**：
- [ ] 能数出 ≥ 4 根外露肋骨
- [ ] 断裂尾段明显低于船身且向云里沉
- [ ] 破口是画面最暗处
- [ ] 外壳是铜绿而不是橙铜

### S6 熔管城市 · `lava_tube_city`

**定位**：阿佛洛狄忒的战场（Boss 场地），也是全模组最大人工构筑。三层同心圆台递收，12 只箱子。

**代码体量（精确）**：三层圆台 半径 20 / y0 → 半径 14 / y6 → 半径 8 / y12（外接约 41×15×41）；每层外环墙高 2，**每 6 格开口**；**四角立柱**在 (±18, ±18)，14 格高，顶端 1 格硫晶；第二层环上 **8 根 3 格高的硫晶柱**（半径 10 圆周均布）；第二层中央 **7×7 菱形硫晶铺底 = 酸池**；第三层中央 **3 格高祭台**（深板岩 + 硫晶 + 硫晶）；每层 4 箱。

**材质表**：平台 磨制安山岩；外环墙 **磨制深板岩** `#4a4a4f`；立柱/祭台 深板岩；信标/柱头/酸池 **硫晶块**；酸池液面 硫酸 `#88e048`。**世界生成时是露天的**（挂在云岛群岛/酸潮滩/金属霜高地；"熔管"是设计草案意象，代码里没有顶盖）。

**已知代码缺陷（美术先按"有根"画，代码后修）**：四角立柱与圆台之间有 5 格空隙、底下是空气，
实际生成是悬空的四根柱子；概念图请画成从地面长到 14 格的独立支柱，并在验收表里记一条待修。

**识别点**：
1. **三层同心圆**，每层比下一层缩进 6 格、抬高 6 格——婚礼蛋糕式递收；
2. **四角立柱**（14 格）比任何一层都高，而且**站在圆台之外**（±18,±18 到中心 25.5 格 > 外台半径 20），形成"框"把建筑框住；
3. **8 根硫晶柱环 + 中央 3 格祭台**双重心，硫晶是全场唯一暖光。

**构图**：16:9，居高俯视（仰角 40–45°），**必须让三层同时可见**（这是它的身份）；对角构图，四角立柱各自入画。

**专属禁止**：画成圆形竞技场/罗马斗兽场 / 三层完全同心同大小 / 加圆顶 / 把酸池画成熔岩（颜色必须是酸绿而不是橙红）/ 加阶梯（代码里层间没有楼梯——**可以画成"缺口处有临时木梯"但要标注为提案**）。

**验收**：
- [ ] 三层半径递减关系一眼可读（20 / 14 / 8）
- [ ] 四角立柱高于所有层
- [ ] 硫晶柱可数出 8 根
- [ ] 中央祭台是最亮的一点
- [ ] 橙红（熔岩）与酸绿（硫酸）没有混用

### S7 启明星祭坛 · `phosphoros_altar`

**定位**：结局点。生成在云岛群岛 **最高层 y 270–300**、密度 1/400（最低），必须是"全模组最空旷、最亮、最仪式化"的构筑。

**代码体量（精确）**：9×9 平台（切角）、厚 2；**三级阶梯**：第 1 级半径 4（平台本身）、第 2 级半径 3、第 3 级半径 2，每级 1 格高，第 2/3 级用切制铜；**四角 4 格高硫晶柱**（±3,±3）；中央 **3 格核心**：硫晶 / 切制铜 / 硫晶（自下而上）；1 只结局箱。

**材质表**：平台 平滑石；台阶 切制铜 ≈`#c16d4f`；柱与核心 硫晶块；环境 天光 + 云海 + 高空无遮蔽。

**识别点**：
1. **纯正的三级台阶**（直径 9 / 7 / 5），俯视是三个同心方；
2. **四根等长晶柱**（4 格）比台阶高，围出一个"井"；
3. **中央三格核心**：上下硫晶夹一层铜，是唯一竖立的亮点，也是"启明星核"的方块形态。

**构图**：1:1 或 4:3，**正俯视 55–60° 偏高**（要看清三级台阶）；背景只有天与云，**不要地面**——它悬在最高处；光从画面右上方穿过晶柱。

**专属禁止**：加雕像/加拱门/加围栏/把核心画成悬浮球体（必须是 3 格方块堆）/ 台阶超过 3 级 / 周围加建筑。

**验收**：

- [ ] 四柱等长且高于台阶面
- [ ] 中央是"三格竖塔"，上下同色中间异色
- [ ] 画面里没有任何其它建筑

### S8 梦眠祭坛 · `dreamsleep_altar`（月球）
