# 持握姿态与装备动画

## 1. display 变换

装备的"动作"首先是静态姿态。能背原版预设就别自己调；必须自定义时，四项都要给：

```json
"display": {
  "thirdperson_righthand": {
    "rotation":    [0, -90, 55],
    "translation": [0, 1, 0.5],
    "scale":       0.85
  }
}
```

- `rotation` 用角度，顺序 Z·Y·X；长剑类常用的 `[0,-90,55]` 是"剑尖朝上、刃朝外"。
- `translation` 以 **16 = 1 方块**为单位，位移量通常很小（0~2）；靠大位移对位置说明几何本身没对齐。
- `scale` 用来适配长度档位，不要用来"修正握把位置"。
- 穿戴件没有 display：姿态 100% 来自骨骼绑定（`head/body/arm/leg`），骨骼原点必须和原版一致。

## 2. 装备动画的类型

| 动作 | 用法 | 长度 | 循环 |
|---|---|---|---|
| 面甲 / 护目镜开合 | 单轴旋转，开到底定格 | 0.4~0.6 s | once 或 hold |
| 武器旋转 / 悬浮 | 单轴匀速，或上下浮动 | 1.5~3 s | loop |
| 裙甲 / 披风 / 链饰摆动 | 小角度往返 + 相位差 | 跟随走路周期 | loop |
| 能量/发光脉动 | 缩放或贴图动画，不要改几何 | 1~2 s | loop |

- 装备动画**只做次级动作**：主体位移交给玩家动作（走路/挥砍），模型里不要再加大幅位移，否则叠加起来会穿模。
- 链饰、流苏这类悬挂件做成骨链（每节一个骨），摆动才有跟随；整根一个骨只会僵直前甩。
- 循环动作结尾必须与开头同姿态；曲线用 `catmullrom`，开合/打击瞬间用 `linear`。

## 3. 导出与校验

- 导出前跑一次 `validate_animations`：键越界、键冲突、地面穿透、部件脱离都要清零。
- `sample_pose` 可以在不渲染的情况下取任意时刻的骨骼姿态，用来核对"到底转了多少度"。
- 装备动画多数走 GeckoLib / Bedrock 格式；这两种格式的骨名与缩放约定不同，导出后要在游戏内看一次，别只看 Blockbench 预览。

## 4. 常见问题

| 现象 | 原因 |
|---|---|
| 游戏里比 Blockbench 里"翻了个方向" | display 的 rotation 与模型自身朝向叠加，模型应保持朝向 -Z |
| 手持位置对，但挥砍时穿模 | 装备动画加了位移，与玩家动作叠加 |
| 面甲开合时穿进头盔 | 转轴不在铰链位置；铰链要放在开合边的实际旋转中心 |
| 链饰甩得像硬棍 | 整根只有一个骨，或每节没有相位差 |
