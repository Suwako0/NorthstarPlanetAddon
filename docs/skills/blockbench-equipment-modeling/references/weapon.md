# 手持装备：武器 / 工具 / 饰品

## 1. 握把对齐（最常见的"手悬空/握在刃上"）

- 物品模型渲染时先 `translate(0.5) + display`，**手就在模型坐标原点**。
- 所以：**握把中心必须在模型原点 (0,0,0)**，y=8 是物品模型的"原点平面"，握把中点要对齐到它。
- 长柄武器整根长度按原版量级：短剑 16、剑 20、巨剑 26、长柄 38、匕首 12（单位 = 1/16 方块）。长度变了要**平移**，不是放大。
- 握把位置错了的表现：手悬在剑柄旁边、握在刃身中段、武器横着飞出去。

## 2. display 预设

| 类型 | display | 说明 |
|---|---|---|
| 短刃 / 单手剑 | `handheld` | scale 1.0~1.2 |
| 长剑 / 巨剑 / 长柄 / 长枪 | `big_handheld` | 靠平移撑长度，**不要放得更大** |
| 盾 / 饰品 | `handheld` 或自定义 | 需要自定义时显式写 rotation/translation/scale |

- 手持模型**不要**在模型里预先把武器旋转 45°——旋转交给 display，几何保持轴对称或沿 y 轴向上，否则在 GUI 里会歪。
- 同一把武器若要 GUI 图标，另出一张 2D `_gui.png`，不要让 3D 模型兼职图标（3D 渲染做图标既糊又慢）。

## 3. 形体分层（避免"一个方块 + 一张贴图"）

至少要有：主体（刃/头/杆）→ 结构件（护手、箍、铆钉、缠绳）→ 装饰件（宝石、刻纹、流苏、配重）。

- 刃身用**分段**而不是一整块：每段独立 cube，UV 各占一块，贴图才能画出刃口亮线。
- 单侧对称的武器（如单刃斧）只建一侧再镜像；完全对称的武器必须严格镜像。
- 尖端做 2~3 级收窄，平头的剑看着像木板。
- 部件数参考：3D 武器装备件一般 ≥15 个 element（低于这个数就是"棍子 + 刀片"）。

## 4. 与注册/贴图的衔接

- 注册名 → 贴图路径 → 模型路径必须同名：`<modid>:<name>` → `assets/<modid>/textures/item/<name>.png` + `models/item/<name>.json` + `lang` 条目。
- 3D 模型的贴图用**一套图集**（64×64 或 128×128），所有部件 UV 都在这张图里；不要每个部件一张 PNG。
- 图集尺寸写在模型的 `texture_size` 里，与导出脚本一致；改了图集尺寸要同步改模型。

## 5. 自检

- [ ] 握把中心在原点，`display` 用对了预设
- [ ] 模型长度符合原版量级，没有靠 scale 硬撑
- [ ] 刃/头有分段收窄，不是单块方块
- [ ] 图集尺寸、`texture_size`、导出的 PNG 三者一致
- [ ] 游戏内手持位置正确（这是唯一可信的验收，需要用户截图）
