# 护甲建模事故档案（molten_core 2026-11-22）

这一轮在熔核套上踩了 5 个坑，逐个都花了 1–3 次返工。全部记录在此，**新护甲必须逐条对照**，
并且必须跑 `python tools/check-armor.py --set <套装名>` 才能交付。

---

## 坑 1 · 手部"黑色方块"（最费时的一个）

**症状**：穿胸甲后，手部末端出现黑色方块，跟随手臂摆动，换视角能看到它像贴在手上。

**根因**：`layer_1` 的手臂是 **6 个面**拼出来的，我只挖空了四个侧面，漏了 **底面**。

原版 64×32 的手臂盒（起点 `(40,16)`，尺寸 4×12×4）六个面是：

| 面 | 贴图矩形 | 对应部位 |
|---|---|---|
| 顶面 | `(44,16) 4×4` | 肩头 |
| **底面** | **`(48,16) 4×4`** | **手的末端（断面）** ← 黑块就是它 |
| 右侧 | `(40,20) 4×12` | 外侧 |
| 正面 | `(44,20) 4×12` | 前侧 |
| 左侧 | `(48,20) 4×12` | 内侧 |
| 背面 | `(52,20) 4×12` | 后侧 |

侧面上的 12 行 = 手臂 12 个单位（世界 y 24→12）。

**正确挖法**（手 = 底部 3 个单位）：

```python
# 四个侧面：底部 3 行全透明
d.rectangle([40, 29, 55, 31], fill=CLEAR)
# 底面 4x4 也要透明，否则看得到手掌断面
d.rectangle([48, 16, 51, 19], fill=CLEAR)
```

**顺带教训**：一开始我挖了 `y 26..31` 六行，等于前臂下 6 单位裸奔 ——
挖多了和挖少了一样错。手只占最后 2–3 格。

**腿部同理**：腿盒 `(0,16) 4×12×4` —— 顶面 `(4,16)`、底面 `(8,16)`，脚底断面也要挖。

## 坑 2 · 装饰件被护甲壳吃掉

**症状**：3D 部件"看不见"，看到的是暗色外壳；或者胸口、肩甲穿模、走动时闪。

**根因**：vanilla 护甲层是用 `CubeDeformation(1.0)` 画的，**比皮肤外扩 1 单位**。
Blockbench 里没有这层壳，按皮肤尺寸建的件进游戏就埋在壳里。

**规则**：装饰件必须在 X/Z 上比壳再凸出：

| 部件类型 | 需要的额外外扩 |
|---|---|
| 包住肢体的（护腕、腿甲、靴） | **+1.0**，且**只扩 X/Z，不要扩 Y** |
| 贴在躯干/头部的（胸板、领甲、背板） | **+0.6** |
| 本来就悬空的（肩甲、冠刺、链饰） | 0 |

**别做的事**：不要用 `addBox(..., deformation)` —— 那是六面外扩，会把手腕下延 1 单位
重新盖住手，也会让手臂 4 宽变 8 宽（"臃肿"就是这么来的）。
也不要"deformation + 额外 bulk"叠加，两遍外扩必然臃肿。

## 坑 3 · 套筒式肢体甲

**症状**：手臂旁浮着黑方块，跟着手臂摆。

**根因**：`plate_upperarm` 宽 8、深 8，而手臂只有 4 宽 —— 本质是"在手臂上套了个大盒子"。

**规则**：**手臂/大腿/小腿上不要放 3D 套筒**。这些部位交给 `layer_1/2` 的像素甲面；
3D 只做**轮廓件**：盔冠、面甲、肩甲、胸板、腰带、腰垂、链饰、膝甲、靴。
理由：套筒要么比壳小（被吞）、要么比壳大（臃肿），没有中间态。

---

## 坑 4 · 左右不对称

**症状**：左腿到 +3.2、右腿只到 −3.1。

**根因**：Blockbench 的 mirror 是逐件做的，随后"对齐整数网格"让左右各自取整。

**规则**：**导出时只取右侧，左侧由镜像生成**（`tools/bbmodel-export.py` 已实现）：

```python
left_x_range = [-x1, -x0]   # 绕骨骼中线镜像
```

---

## 坑 5 · 薄件 → 零面积 UV

**症状**：`check_model` 报大量 `zero_uv`，游戏里那些面是黑的。

**根因**：box UV 会把小于 1 单位的尺寸取整成 0 像素。

**规则**：所有 cube **对齐整数网格、每条边 ≥ 1 单位**。

---

## 交付前必做

```bash
python tools/bbmodel-export.py                 # 贴图 + box-UV 偏移
python tools/bbmodel-to-java-parts.py          # 模型部件 -> Java 模型类
python tools/check-armor.py --set molten_core  # ← 新增，不通过不要交付
.\gradlew.bat build
```

`check-armor.py` 会拦下：

- 穿戴层尺寸不对
- 手部/脚底断面没挖空（坑 1）
- 装饰件完全埋在护甲壳里（坑 2）
- 手臂/腿骨上存在套筒件（坑 3）
- 左右部件不互为镜像（坑 4）
- 任一 box-UV 面采样到透明像素（坑 5）
